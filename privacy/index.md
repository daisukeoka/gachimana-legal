# プライバシーポリシー

最終更新日：2026年11月4日

ガチマナ（以下「本アプリ」）は、アプリ運営者（以下「運営者」）が提供する、問題集で学ぶアプリです。
このプライバシーポリシーは、本アプリが利用者の情報をどのように集め、使い、守るかを説明するものです。

## 1. 集める情報

### 1.1 アカウント

本アプリは、初めて起動したときに、匿名のアカウントを自動で作ります。
アカウントには、運営者が発行するランダムな ID だけが付きます。**名前・メールアドレス・電話番号などは集めません。**

### 1.2 学習の記録

学習の記録を、アカウントの ID と結びつけて、運営者のサーバーに保存します。

- 解いた問題、選んだ答え、正解か不正解か、解いた日時
- 問題集をどこまで解いたか（途中でやめたところから再開するため）
- 問題ごとの、続けて正解した回数・解いた回数・正解した回数（選択肢の数を決めることと、復習のため）

### 1.3 「間違いを報告」で送った内容

問題・正解・解説の誤りを報告したときは、報告の種類（問題文・正解・解説・その他）と、記入したコメントを、アカウントの ID と結びつけて保存します。
**コメントには、個人を特定できる情報を書かないでください。**

### 1.4 端末の中だけに保存する情報

次の情報は利用者の端末の中だけに保存し、運営者には送りません。

- ログインの状態（同じ端末で、同じ学習の記録を使い続けるため）
- 「本番と同じ択数で解く」などのアプリの設定

### 1.5 広告に関する情報

本アプリは、Google の AdMob を使って広告を表示します。AdMob は、広告を配信し効果を測るために、次の情報を集めることがあります。

- 端末の情報（機種、OS のバージョンなど）
- IP アドレスから推定される、おおよその位置
- 広告の表示やタップの記録
- 広告識別子（IDFA）。**「トラッキングを許可」したときだけ**使われます

トラッキングを許可すると、利用者の興味に合わせた広告が表示されやすくなります。許可しなくても、本アプリの機能はすべて使えます。
許可は、端末の「設定」→「プライバシーとセキュリティ」→「トラッキング」から、いつでも変えられます。

AdMob による情報の扱いは、Google のプライバシーポリシーに従います。

- Google のプライバシーポリシー：https://policies.google.com/privacy
- Google の広告に関するポリシー：https://policies.google.com/technologies/ads

### 1.6 通信の記録

本アプリが運営者のサーバーと通信するとき、サーバーを提供する事業者のログに、IP アドレスや通信の日時が記録されることがあります。

## 2. 使う目的

集めた情報は、次の目的にだけ使います。

1. 学習の記録を保存し、途中から再開できるようにするため
2. 間違えた問題・わからなかった問題を復習できるようにするため、また、続けて正解した回数に応じて選択肢の数を変えるため
3. 報告された誤りを確かめ、問題・正解・解説を直すため
4. 広告を表示するため
5. 不正な利用を防ぎ、本アプリを安定して動かすため

## 3. 第三者への提供

運営者は、次の場合を除いて、利用者の情報を第三者に提供しません。**利用者の情報を売ることはありません。**

- 本アプリを動かすために、下の「5. 使っている外部のサービス」に預けるとき
- 法令に基づいて求められたとき

## 4. 保存する場所

学習の記録と報告は、Supabase（データベースのサービス）の、日本（東京）にあるサーバーに保存します。
利用者は自分の記録だけを読み書きでき、ほかの利用者の記録は読めない設定にしています。

## 5. 使っている外部のサービス

| サービス | 使う目的 | プライバシーポリシー |
|---|---|---|
| Supabase | アカウントと学習の記録の保存 | https://supabase.com/privacy |
| Google AdMob | 広告の表示 | https://policies.google.com/privacy |

## 6. 記録の削除

本アプリの「設定」→「学習の記録を消す」から、学習の記録・報告・匿名のアカウントをすべて消せます。消した記録は元に戻せません。
消したあとは、新しい匿名のアカウントで始まります。

本アプリを削除しただけでは、端末の中のログインの状態は消えますが、サーバーの学習の記録は残ります。記録を消したいときは、本アプリを削除する前に「学習の記録を消す」を使ってください。

## 7. 子どもの情報

本アプリは、大人の学習のためのアプリです。13歳未満の子どもを対象にしておらず、13歳未満の子どもから意図して情報を集めることはありません。

## 8. 安全のための取り組み

通信は暗号化しています。学習の記録は、利用者本人だけが読み書きできるようにしています。

## 9. このポリシーの変更

このポリシーは、本アプリの機能や法令の変更に合わせて改めることがあります。改めたときは、このページの最終更新日を変えます。
